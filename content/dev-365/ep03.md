## What I Did

I had this problem ever since but i never took the time to investigate it.

When my SAAS application is running in production mode, it sometimes fails to connect to the database. The error message indicates that the the connection to the db has fail. I did not know why because in development mode everything works fine.

After some investigation, I remember that this all happen when i migrated to Prisma 7. So I decided to check all the configuration that i did for the migration. And then I found that there was an environment variable that was not set correctly in production mode.

I fixed the environment variable and redeployed the application. Now, the application is able to connect to the database without any issues in production mode.
